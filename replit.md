# JPS School System

Static HTML site (originally hosted on Vercel) migrated to Replit.

## Structure
- `index.html` — main page
- `about/` — about page
- `images/` — static image assets
- `vercel.json` — legacy Vercel cache headers (unused on Replit)

## Running
Served via `python3 -m http.server 5000` on port 5000 (workflow: "Start application").
